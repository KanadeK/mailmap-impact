# Security

Only the latest release receives fixes. This local tool has no network client and
does not send reports anywhere. Reports may contain supplied paths or identity metadata;
review them before sharing. Untrusted inputs are bounded, but this is not a sandbox
against another local process concurrently replacing files.

Use [GitHub private vulnerability reporting](https://github.com/KanadeK/mailmap-impact/security/advisories/new)
for security-sensitive reports. If that channel is unavailable, open a public issue
requesting a private contact without posting exploit details, secrets or private data.
Do not use ordinary issues to publish credentials.
