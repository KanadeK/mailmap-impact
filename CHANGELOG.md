# Changelog

## 0.1.0

- Compare complete mailmaps over raw local authors and committers using native Git.
- Report changed contacts, merge/split witnesses and affected commit/role counts.
- Provide anonymous default reports, optional identity display, text/JSON and CI gates.
- Isolate resolution from source/global/environment mapping configuration.

Limits: local available history only; no co-author trailers, account verification,
GitHub contribution-graph guarantees or history rewriting. See README for resource caps.
